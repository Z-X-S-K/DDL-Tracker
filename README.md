# ApplyOS / Kairesa Coach — GitHub Pages 静态网站

这是一个可直接上传到 GitHub Pages 的静态网站，不需要 npm、React、服务器或数据库。

## 使用方式

1. 解压 zip。
2. 把 `index.html`、`styles.css`、`script.js`、`data.js`、`404.html`、`.nojekyll` 上传到 GitHub 仓库根目录。
3. 打开 GitHub 仓库：Settings → Pages。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main` / `/root`。
6. 保存后等待 Pages 部署。

## 功能

- JD T10/11所学校关键截止日期表
- Oct 15–Nov 1 第一批提交、Nov 15 ED、Dec 31 Regular内部线
- LSAT官方考试节点
- 25个10天周期任务表
- 本地浏览器打卡和CSV导出
- 关键节点ICS下载
- 应急模式/现金流模式/LSAT救援模式建议

## 数据提醒

- Fall 2027 JD申请季很多学校官网通常会在2026年8–9月更新。本网站先按用户提供的最新官网/LSAC公布日期与同月同日逻辑规划。
- LSAT日期来自LSAC 2026–2027 Testing Year官方信息，仍建议报名前再次核对。
- 打卡数据保存在浏览器 localStorage，不会同步到其他设备。
